**Cycle Mouse** creates an infinite horizontal desktop across multiple monitors by seamlessly wrapping the mouse pointer from one side of the monitor layout to the opposite side.

Instead of treating the leftmost and rightmost displays as hard boundaries, Cycle Mouse connects them together.

When the pointer reaches the right edge of the last monitor, it instantly reappears at the left edge of the first monitor. The same behavior works in the opposite direction.

## Features

- **Infinite horizontal mouse movement**
  - Move continuously across all connected monitors.
  - Crossing the outer boundary wraps the pointer to the opposite side.
- **Seamless transitions**
  - No visible animation or teleportation effect.
  - The pointer simply continues moving as if the desktop were infinite.
- **Multi-monitor support**
  - Designed for horizontally arranged displays.
  - Works across the complete virtual desktop.
- **Window dragging**
  - Application windows can be dragged across the monitor boundaries.
  - When a dragged window reaches the outer edge, it continues from the opposite side while maintaining the drag operation.
- **Continuous cycling**
  - Monitor 1 → Monitor 2 → Monitor 3 → Monitor 1 → ...
  - The cycle can continue indefinitely.

## Use Cases

Cycle Mouse is particularly useful for multi-monitor workstations where the displays form a single horizontal workspace.

Examples include:

- Developers working across multiple displays
- System administrators and IT professionals
- Traders and monitoring workstations
- Video and audio production
- Productivity setups
- Large desktop environments
- Anyone who frequently moves the cursor between multiple monitors
